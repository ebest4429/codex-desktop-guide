# Codex Desktop 가이드 마스터플랜

**현재 활성 플랜:** `codex-desktop-guide-phase3.md`

> 이 문서는 Codex Desktop 가이드 웹사이트의 전체 방향·목표·단계를 기록한다.
> 세션이 바뀌어도 협의 맥락을 이어받을 수 있도록 **결정사항 + 취지**를 함께 기록한다.
> 결정만 있고 취지가 없으면 다음 세션 AI가 맥락 없이 잘못된 방향으로 해석한다.

---

## 프로젝트 정체성

Codex Desktop의 전체 기능과 사용법을 다루는 가이드 웹사이트.
다크 테마, Pretendard 폰트, 리사이즈 가능한 사이드바, 아코디언·카드형 레이아웃을 사용한다.

---

## 전체 Phase 구조

| Phase | 이름 | 상태 |
|-------|------|------|
| Phase 1 | 기술스택 협의 + 전체 구조 설계 | ✅ 완료 |
| Phase 2 | 기본 UI 구현 (레이아웃·테마·네비게이션) | ✅ 완료 |
| Phase 3 | 콘텐츠 구현 (페이지별 상세 작성) | 🔄 진행 중 |
| Phase 4 | 검색 기능 + 완성 + 배포 | 🔲 대기 |

> **Phase 2 대기 취지:** 기술스택과 전체 구조가 확정되지 않은 상태에서 구현 진입 시
> 방향 수정이 반복된다. Phase 1에서 모든 구조·기술 결정 완료 후 Phase 2 진입.

---

## 확정 사항

### 기술스택 (확정)

> **취지:** 리사이즈 사이드바·필터링·아코디언·카드형 등 커스텀 레이아웃 요구사항이 많아
> 프레임워크 제약이 적고 디자인 자유도가 높은 Next.js + Tailwind CSS를 선택.
> 배포는 설정이 간단한 Vercel로 결정.

- 프레임워크: Next.js
- CSS: Tailwind CSS
- 배포: GitHub Pages

### 디자인 방향 (확정)

> **취지:** 프로젝트 구상 단계에서 사용자가 직접 명시한 내용.
> 이후 협의에서 변경 시 이 항목을 수정하고 변경 취지를 기록한다.

- 테마: 다크 테마
- 폰트: Pretendard
- 소제목: 16px~18px / 본문: 14px 이상
- 타이틀 영역: 80px~100px + 검색바 중앙배치
- 네비게이션: 사이드바 (리사이즈 가능 + 필터링 방식)
- 상세 영역: 아코디언 컨테이너
- 레이아웃: 카드형 / 리스트형
