# Phase 1 사전설계 — 기술스택 협의 + 전체 구조 설계

> 참조: `.claude/plans/codex-desktop-guide-master.md`
> **이 문서의 목적:** Phase 1 진입 전 협의·결정·설계 범위를 사전 정의.
> 구현은 하지 않는다. 모든 구조·기술 결정 완료 후 Phase 2 진입.
> 취지: 소급 작성 (Phase 1 완료 후 기록 목적으로 작성. 실제 결정 내용 반영).

---

## Phase 1 목표

기술스택·페이지 구조·콘텐츠 범위·디자인 시스템을 협의하고 확정한다.
확정되지 않은 항목이 하나라도 있으면 Phase 2로 진입하지 않는다.

---

## 전제 조건

- 프로젝트 정체성 확정: Codex Desktop 가이드 웹사이트
- 사용자 구상: 다크테마, Pretendard, 사이드바(리사이즈+필터링), 아코디언, 카드형

---

## 협의 항목 및 순서

### 1. 기술스택 결정

협의 대상:
- 프레임워크: Next.js (App Router) 선택
- CSS: Tailwind CSS 선택
- 배포: GitHub Pages 선택
- 폰트: Pretendard Variable CDN

결정 취지: 커스텀 레이아웃 요구사항이 많아 프레임워크 제약 없는 조합 선택.

### 2. 전체 페이지 구조 설계

확정 내용:
- 최상위 메뉴: 개요 / 사용법 / 주요기능 / 메뉴소개 + 구분선 + 모델/컨텍스트/구독/스킬/스레드/MCP
- 페이지 원칙: 최대 1단계 중첩. 기능 1개=페이지 1개. 구분선 이하=단일 페이지+아코디언
- URL 구조: /overview, /usage/[slug], /features/[slug], /menu/[slug], /model 등

### 3. 콘텐츠 구조 설계

확정 내용:
- 개요(2): Codex Desktop이란? / 빠른 시작
- 사용법(3): 기본 사용법 / 대화 시작하기 / 파일 작업
- 주요기능(5): 멀티모달 입력 / 코드 실행 / 웹 검색 / 파일 처리 / 확장 기능
- 메뉴소개(13): 파일 / 편집 / 보기 / 도구 / 설정 / 프로젝트 / 스레드 / 모델 선택 / 컨텍스트 / 스킬 / MCP / 도움말 / 업데이트
- 독립 섹션(6): 모델 / 컨텍스트 / 구독 / 스킬 / 스레드 / MCP

### 4. 디자인 시스템 정의

확정 내용:
- 배경: #0d0d0d(기본), #161616(사이드바), #1e1e1e(카드)
- 텍스트: #f5f5f5(기본), #b0b0b0(보조), #6b6b6b(muted)
- 강조: #10a37f (그린)
- 테두리: #2e2e2e
- 타이포: Pretendard Variable, 14px 기본, 28px~13px 범위
- 컴포넌트 8종: Sidebar, SearchBar, Card, Accordion, Breadcrumb, CodeBlock, Badge, Divider
