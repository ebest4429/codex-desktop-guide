# Phase 4 — 검색 기능 + 완성 + 배포

> 참조: `.claude/plans/codex-desktop-guide-master.md`
> 사전설계: `.claude/plans/designs/codex-desktop-guide-phase4.md`
> **이 Phase의 목표:** 검색 기능 연결, 모바일 반응형 보완, 전체 QA 후 최종 배포 완성.
> Phase 3까지 완성된 콘텐츠를 기반으로 품질을 높이는 단계.

---

## 작업 항목

### 0. UI 개선 (검색창·타이틀 영역 재설계)

> 취지: Phase 4 진입 시 사용자 요청으로 추가된 UI 개선 작업.
> 사이드바 검색창과 메인 검색창의 역할 중복 해소 + 레이아웃 완성도 향상.

- ✅ TitleBar 신규 컴포넌트 — 좌측 사이트명 + 중앙 선택경로(섹션·페이지) + 하단 중앙 검색창
- ✅ 타이틀 영역 sticky — 스크롤 시에도 상단 고정
- ✅ 사이드바 검색창·필터 로직 제거 — 순수 네비게이션만 유지
- ✅ layout 재구성 — TitleBar(전체 상단) + 사이드바+콘텐츠(하단 flex-row)

### 1. 검색 기능 구현

> 취지: Phase 2에서 헤더 검색바 자리만 잡아뒀음. Phase 4에서 실제 기능 연결.
> 정적 사이트이므로 클라이언트 사이드 검색으로 구현.
> 라이브러리 선택은 Phase 4 진입 시 협의 후 결정. 사전 선택 금지.

- 🔲 검색 라이브러리 협의 및 결정 (pagefind / fuse.js / 직접 구현)
- 🔲 콘텐츠 인덱싱 (빌드 시 자동 생성)
- 🔲 검색바 기능 연결 (실시간 결과 표시)
- 🔲 검색 결과 드롭다운 또는 결과 페이지 구현

### 2. 모바일 반응형 보완

> 취지: Phase 2, 3는 데스크톱 우선으로 구현. Phase 4에서 모바일 뷰 보완.

- 🔲 사이드바: 모바일에서 숨김 + 햄버거 메뉴 토글
- 🔲 레이아웃: 모바일 1단 구조
- 🔲 카드/아코디언: 모바일 너비 최적화
- 🔲 헤더: 모바일 높이 조정

### 3. 전체 QA

> 취지: 콘텐츠 완성 후 실제 배포 URL에서 전체 기능 검증.

- 🔲 29개 페이지 전수 확인 (콘텐츠 누락, 링크 오류, 레이아웃 깨짐)
- 🔲 사이드바 필터링 — 모든 항목 정상 동작 확인
- 🔲 배포 URL에서 전체 페이지 확인
- 🔲 검색 기능 동작 확인

### 4. 성능 최적화 (선택)

> 취지: 필수 아님. QA 완료 후 여유 있을 때 진행.

- 🔲 이미지 최적화 (스크린샷 사용 시)
- 🔲 폰트 로딩 최적화
- 🔲 빌드 산출물 크기 확인

### 5. 최종 배포 확인

- 🔲 GitHub Actions 워크플로 정상 실행 확인
- 🔲 배포 URL 전체 기능 최종 검증
- 🔲 커스텀 도메인 설정 (필요 시 — 사용자 결정)
